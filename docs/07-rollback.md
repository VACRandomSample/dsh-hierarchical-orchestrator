**Симптом (23:00):** пользователь не мог создать новую сессию; открытые чаты выглядели «пропавшими».

**Причина:** оверрайд `preset-cordis` в бандле содержал скопированное из штатного патча `!!js`-выражение `customSkillDirs` (`createRequire(baseUrl).resolve('@deepseek-ai/dsh-agent-preset/package.json')`). Из workspace-бандла это разрешение не резолвится → ревизия пресета `cordis` не активировалась → создание сессий на этом пресете падало. Превентивный вывод секции «Resolve assets from installed packages» в `editing-cordis-compositions` был нарушен мной при копировании.

**Действия:** бандл отключён (`set_bundle enabled=false`, applied 23:02) — приложение вернулось на штатную композицию; выражение удалено из патча (2026-11-12). Данные чатов не затрагивались (projcache проверен — заголовки и история целы).

**Отдельное наблюдение (не связано с бандлом):** boot-ошибка `@local/dsh-locale-ru: failed` существует с 09.11 (краш-логи `crash-2026-11-09T07-*`) — русификатор не активируется в web-boot до любых изменений от этой работы. Приложение при этом работает.

**Урок для переустановки:** в секции `preset-cordis` бандла строка `skill-filesystem` должна идти без `customSkillDirs` (уже исправлено в исходнике бандла). Перед включением бандла — проверять отсутствие `!!js`-выражений, ссылающихся на пакеты вне бандла.
